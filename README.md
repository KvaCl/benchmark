# HTTP Bench

Консольная программа для проверки доступности HTTP-серверов и
сбора статистики времени ответа.

## Возможности

- проверка нескольких HTTP/HTTPS серверов;
- несколько запросов к каждому серверу;
- подсчет успешных запросов;
- подсчет HTTP-ошибок;
- подсчет сетевых ошибок;
- расчет минимального времени ответа;
- расчет максимального времени ответа;
- расчет среднего времени ответа;
- валидация URL;
- валидация количества запросов;
- чтение списка URL из файла;
- сохранение результата в файл;
- параллельное выполнение запросов с помощью asyncio,aiohttp.
